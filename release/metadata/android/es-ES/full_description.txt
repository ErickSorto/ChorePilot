Llevar la casa es más fácil cuando todos saben qué hay que hacer. ChorePilot ayuda a familias, parejas y personas que comparten casa a organizar las tareas del hogar, crear una rutina de limpieza y ver qué está hecho.

Encuentra tareas con una foto
¿No sabes por dónde empezar? Usa una foto de una habitación para recibir sugerencias de tareas con IA. Revisa y edita las ideas antes de añadirlas al plan. Tú decides qué sirve para tu casa.

Reparte las tareas por habitación
Crea una lista compartida para la cocina, el baño, la sala y otros espacios. Añade instrucciones y asigna las tareas para que todos sepan qué hacer y quién se encarga.

Organiza una rutina a tu medida
Crea tareas para una sola vez o tareas recurrentes. Elige cuándo se repiten y rota los responsables para repartir el trabajo con el tiempo.

Conoce a tu compañero de tareas
Elige una ardilla, un pingüino o un gato como mascota virtual. Las tareas completadas ayudan a tu compañero a ganar XP y subir de nivel, con un poco de ánimo extra para el día a día.

Comprueba el resultado con fotos
Para las tareas que necesitan revisión, pide una foto al terminarlas. Los administradores de la casa pueden revisar los envíos, aprobar el trabajo o pedir otra foto.

Menos cosas que recordar
Recibe recordatorios de tareas próximas a vencer o atrasadas, además de avisos sobre asignaciones y revisión de fotos. Elige qué tipos de notificaciones quieres recibir.

Mira cómo cuenta tu esfuerzo
Consulta informes de tareas completadas, planificadas y atrasadas. Sigue el progreso con el tiempo y haz visible el trabajo que mantiene la casa en orden.

Desde guardar los platos hasta limpiar el baño cada semana, dale un lugar a cada tarea en tu plan.
